## CRITICAL RULES (MUST FOLLOW)

### Rule 1: Indicator Source Input
All indicators require `source=data` parameter:
- `ma = indicator.ma(source=data, period=20)`
- `rsi = indicator.rsi(source=data, period=14)`

### Rule 2: Multi-Output Indicators - MUST Use Tuple Unpacking
Some indicators have multiple outputs. You MUST use tuple unpacking to receive them:

**Bollinger Bands** (3 outputs: upper, middle, lower):
```python
upper, middle, lower = indicator.bollinger_bands(source=data, period=20)
# Then use directly: close < lower, close > upper
```

**MACD** (3 outputs: line, signal, histogram):
```python
line, signal_line, histogram = indicator.macd(source=data)
# Then use directly: line > signal_line
```

### Rule 3: Direct Variable Usage - NO Dictionary Access
After tuple unpacking, use variables DIRECTLY. NEVER use dictionary/subscript syntax:

**WRONG (FORBIDDEN):**
- `data['close']` ← use `close` instead
- `bollinger_bands['lower']` ← use `lower` after tuple unpack
- `rsi['values']` ← use `rsi` directly

**CORRECT:**
- `close`, `open`, `high`, `low`, `volume` ← data columns available directly
- `lower`, `upper`, `middle` ← after tuple unpacking
- `rsi`, `ma`, `line` ← single-output indicators
- `rsi`, `ma`, `line` ← single-output indicators

### Rule 4: Signal Conditions
Pass conditions directly to `signal.buy()` or `signal.sell()`:
```python
signal.buy(condition=close < lower and rsi < 30)
signal.sell(condition=close > upper and rsi > 70)
```

### Rule 5: DSL Syntax - NOT Python
This is a DSL for building graphs, NOT a Python script:
- **NO** pandas, dataframes, df[], ta.trend
- **NO** def, for, while, print
- **NO** intermediate boolean variables
- **ONLY** node instantiation assigned to variables

### Rule 6: Variable Consistency
NEVER use a variable that hasn't been assigned a value.
- **WRONG**: `signal.buy(condition=my_imaginary_condition)`  (Error: undefined variable)
- **RIGHT**: 
  ```python
  buy_cond = (close < lower) and (rsi < 30)
  signal.buy(condition=buy_cond)
  ```
- **RIGHT (Inline)**: `signal.buy(condition=close < lower)`

**Example 3: Golden and Death Cross (Crossing Events)**
For a crossover strategy, use the exact ports `fast_line` and `slow_line`. One crossover series returns 1 for an upward cross, -1 for a downward cross, and 0 otherwise. Compare it to the required value explicitly in each signal condition.
```python
data = data.fetch_stock(symbol="AAPL", market="us", timeframe="1d")
ma_fast = indicator.ma(source=data, period=5)
ma_slow = indicator.ma(source=data, period=20)
cross = indicator.crossover(fast_line=ma_fast, slow_line=ma_slow)
signal.buy(condition=cross == 1)
signal.sell(condition=cross == -1)
```
